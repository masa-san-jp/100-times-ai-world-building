# 合格ラインの確認：性質の違う入力で世界全体の基準を満たせるか

世界全体の合格ライン（`config/world/world_criteria.yaml`）が、特定の入力に合わせた値ではなく、性質の違う入力でも達成できる目標かを確かめた結果です（#100）。[モデル比較の作例](../model_comparison/README.md)の入力（塩の盆地、日本語）に、性質の違う入力（英語・制度と記録の方式を含む）を 1 つ加えています。

この作例は閲覧用です。エンジンの仕組み（コード・設定・プロンプト・テスト）からは参照しません。

## 条件

| 項目 | 値 |
|---|---|
| 生成・判定モデル | `qwen3.8:27b` |
| 反復の上限 | 40 |
| 同時に作る件数 | 4（`--parallel-builds 4`） |
| seed | 1 |
| コンテキスト長 | 16384 |
| コード | `main` の `b01403f` |

## 結果

| 入力 | 停止理由 | 反復 | 採用 | 所要時間 |
|---|---|---|---|---|
| [河口の高床の街（英語・制度と記録の方式を含む）](river_city_en/final/world_bible/README.md) | すべての基準を達成（coverage_met） | 33 | 25 | 約 4.8 時間 |

## 判断

追加した入力でも、反復の上限内にすべての基準を達成しました。言語も内容も異なる 2 つの入力（#73 の塩の盆地と、この入力）で達成できたので、合格ラインは入力によらず達成できる目標と判断し、値を変えません。
