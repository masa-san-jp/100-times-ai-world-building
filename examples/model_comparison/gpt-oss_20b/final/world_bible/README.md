# 世界設定資料

## 概観

### [塩原盆地](entities/e1.md)

塩原盆地は内陸の盆地で、雨季はほとんど降らず、主に地下の古い導水路から水を得ている。この盆地では塩採掘が主要産業であり、採掘週ごとに採掘組合が生産量を管理し、共管委員会が資源配分を調整する。水番家系は導水路の保守を担当し、日々の水消費はm3dで測定される。乾季には水祭が行われ、自治議会が住民の意見を代表して政策を調整する。

### [水源監督会](entities/e2.md)

水源監督会は盆地暦の採掘週ごとに古い導水路から抽出される水量をm3dで測定し、結果を共管委員会へ報告する。乾季の水祭時に水質を検査し、雨季の降水がほぼ無い状況下で資源配分を監視する。水源監督会は採掘組合と水番家系の対立を調整し、平均塩生産量52000 kgを統計する。自治議会と協働し住民の意見を政策に反映する。

### [塩原労働団体](entities/e3.md)

塩原労働団体は塩採掘労働者の組織で、盆地暦の採掘週に毎週の塩生産量（kg）を管理し、共管委員会に報告する。水番家系が保守する古い導水路からの水消費量（m3d）を調整し、乾季の水祭で水質検査結果を共有する。採掘組合との資源配分協議に参加し、自治議会の政策調整に影響を与える。

### [古導水路争議](entities/e4.md)

古導水路争議は紀元前3世紀に建設された導水路の管理権を巡る争いであり、採掘組合と水番家系の間で権益が分断された。これが現在の塩原盆地における水供給管理と塩採掘の対立の根源で、共管委員会や自治議会の設立へとつながった。

### [水道管理協議会](entities/e5.md)

水道管理協議会は、盆地暦の採掘週・水祭・乾季・雨季に沿って、古導水路から抽出される水をm3dで測定し、採掘組合と水番家系の間で水資源の配分を協議する。協議会は水番家系に属する血縁集団が中心で、共管委員会の下位委員会として機能し、水質検査結果を共有し、塩生産量（kg）と水消費量のバランスを調整する。
