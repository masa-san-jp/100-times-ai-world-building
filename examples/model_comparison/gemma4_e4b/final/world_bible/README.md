# 世界設定資料

## 概観

### [塩盆地](entities/e1.md)

塩盆地は、雨がほとんど降らない乾燥した内陸の盆地であり、経済活動は塩の採掘に依存している。生活用水は地下の古い導水路から供給され、その管理権を巡り、採掘組合と水番の家系が「導水路管理評議会」や「水番血統評議会」といった制度のもとで対立している。技術的には「塩石」や「水滴」を用いて資源管理が行われ、時間は「塩月暦」に基づいて計測される。

### [水番家系の水利権主張](entities/e5.md)

水番家系による資源管理の実践は、地下導水路という共有資源の利用権と安全管理に関する規範を定めることを目的とする。この実践は、「水番血統評議会」の権限に基づき、「塩月暦」の「水番潮」などの特定の基準点を参照し、水量の配分や導水路の維持管理に関わる判断を行う。具体的には、「塩水尺」を用いた水位の測定や、「水滴」単位での水量管理が伴い、採掘組合との権力構造における一方の立場を構成している。
