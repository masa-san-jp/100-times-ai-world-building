# 世界設定資料

## 概観

### [塩盆地](entities/e1.md)

塩盆地は、降水量が極めて少ない内陸の盆地であり、地域の生存基盤となる水は地下の古い導水路から供給されている。この環境下では、塩の採掘が経済の中心となり、採掘組合と水番家系の間で導水路の管理権を巡る長期的な対立が生じている。紛争審議会が規範に基づく裁きを担い、伝承会が技術と知識を次世代に継承する。塩暦の採掘期や水枯期など、計測体系が季節的変動を規定し、塩量、水量、導程といった単位が資源の管理と分配の基準として機能している。

### [水権裁定規則](entities/e8.md)

水権裁定規則は、降水量が極めて少ない塩盆地(e1)において、地下導水路(s3)からの限られた水資源(s2)の分配と管理権を規範に基づき裁定する制度である。この制約条件下では、水の利用が塩の採掘(s1)と生活の存続に直結するため、管理権を巡る対立(s4)が構造的に生じる。本規則は、採掘組合と水番家系の利害調整を目的とし、紛争審議会が水量や導程の計測データをもとに裁きを行うことで、資源の枯渇期における秩序を維持する機能を持つ。
