# 世界設定資料

## 概観

### [塩盆地](entities/e1.md)

塩盆地は、降雨が極めて少ない乾燥した内陸の盆地であり、地下水資源への依存が経済活動の基盤を規定している。塩の採掘は地下の古い導水路から供給される水に支えられており、塩担で測られる産出量と水尺で測られる水位差のバランスによって制限される。この環境下では、水番家系と採掘組合が導水路の管理権を巡り対立し、塩秤所が中立に計測・記録を行うことで秩序が維持される。塩暦の起算点である水源確保以降、資源分配の規範が共同体の構造を形成してきた。

### [水番家系](entities/e12.md)

水番家系は、塩盆地 (e1) における地下導水路の管理権を世襲する血縁的行政組織である。降雨が極めて少ない乾燥環境下で、限られた水資源の配分と塩採掘の秩序を維持する役割を担う。技術面では、導水路水圧制御を通じて塩面洗掘時の基準水位差1水尺を管理し、生産活動の上限を規定する。政治・規範面では、採掘組合との長期的な対立構造の中で、水配分の権限と義務の境界を定義する規範的権限を有する。塩秤所が中立に計測・記録する塩担や水尺の基準値に対し、家系は運用面での最終的な判断と紛争処理の規範を担い、塩暦の塩年単位で継承される行政的慣行を通じて盆地の資源経済と共同体構造を形成している。

### [導水路統制所](entities/e13.md)

導水路統制所は、塩盆地の乾燥化と地下水源への依存という制約から生じた機関である。降雨がほぼない環境下では、地下導水路の水位差1水尺を維持し、塩面洗掘時の水圧を制御することが技術上の必須条件となる。この物理的限界を管理し、塩担で測られる産出量と水の配分を調整する役割が、水番家系と採掘組合の対立を制度的に拘束する要因として機能している。

### [水資源配分制約](entities/e14.md)

水資源配分制約とは、降雨が極めて少ない内陸盆地という地理的・気候的条件（s2）と、地下の古い導水路からのみ水を得る技術的依存（s3）から生じる物理的限界である。この環境下では、塩面洗掘における基準水位差1水尺と許容変動幅0.5水尺の維持が技術上の必須条件となり、水圧管理庫による制御が産出量（塩担）と水配分の上限を規定する。導水路統制所がこれらの数値を管理し、塩秤所が計測・記録を行うことで、水番家系と採掘組合の対立が制度的に拘束される。塩暦の塩起以降、限られた資源の効率的な配分と紛争処理の規範が、塩盆地の経済基盤と共同体構造を形成する根本的な要因となっている。

### [水圧管理庫](entities/e15.md)

水圧管理庫は、地下導水路の水位差1水尺と許容変動幅0.5水尺を維持するため、塩面洗掘時の水圧を制御する技術的施設である。降雨がほぼない乾燥環境下では、この圧力調整が塩担による産出量と水配分の物理的上限を規定する。導水路統制所が運用し、塩秤所が計測基準を中立に記録することで、水番家系と採掘組合の管理権対立が制度的に拘束される。塩暦の塩年単位で運用履歴が管理され、盆地の資源経済の安定性を支える基盤施設として機能している。

### [塩起の水源確保](entities/e16.md)

塩起の水源確保は、降雨が極めて少ない内陸盆地の環境下で、地下の古い導水路から水を引く技術的基盤を確立した歴史的出来事である。この水源の確保を起点として塩暦が起算され、水番家系が導水路の管理権を世襲する権力構造が形成された。塩面洗掘時の基準水位差1水尺と許容変動幅0.5水尺の維持が技術上の必須条件となり、水圧管理庫による制御が塩担で測られる産出量と水配分の上限を規定する。この物理的限界と管理権の帰属を巡り、水番家系と採掘組合の間で長期的な対立が生じ、塩秤所が中立に計測・記録を行うことで秩序が維持される現存する政治的・経済的構造の起源となった。

### [導水路管理権世襲規](entities/e17.md)

導水路管理権世襲規は、塩盆地の地下導水路の管理権を水番家系に世襲させることを定める規範的文書である。塩起の水源確保を起点とする塩暦の記録体系に基づき、採掘組合との権限境界を法的に固定化する。本規は、導水路統制所が維持する基準水位差1水尺と許容変動幅0.5水尺の運用権限を、血縁的行政組織である水番家系に帰属させる。塩秤所による塩担や水尺の計測記録を紛争処理の根拠とし、降雨に依存しない乾燥環境下での水配分秩序と技術的制約の法的拘束力を規定する。

### [塩起水源確保](entities/e18.md)

塩起の水源確保(e16)は、塩盆地(e1)の乾燥環境下で地下導水路から塩採掘場へ水を供給する技術的基盤を確立した歴史的出来事である。この確保を起点として塩暦が起算され、水番家系(e12)が導水路の管理権を世襲する権力構造が形成された。技術面では、塩面洗掘時の基準水位差1水尺と許容変動幅0.5水尺の維持が必須条件となり、水圧管理庫による制御が塩担で測られる産出量と水配分の上限を規定する。この物理的限界と管理権の帰属を巡り、水番家系と採掘組合の間で長期的な対立が生じ、塩秤所が中立に計測・記録を行うことで秩序が維持される。

### [乾燥盆地の地下水源依存](entities/e19.md)

乾燥盆地の地下水源依存とは、降雨が極めて少ない内陸盆地という地理的制約と、地下の古い導水路からのみ水を得る技術的依存が重なり、水資源配分制約として機能する物理的限界状態である。塩面洗掘時の基準水位差1水尺と許容変動幅0.5水尺の維持が必須となり、水圧管理庫による制御が塩担で測られる産出量と水配分の上限を規定する。導水路統制所がこれらの数値を管理し、塩秤所が計測・記録を行うことで、水番家系と採掘組合の対立が制度的に拘束される。塩暦の塩起以降、限られた資源の効率的な配分が共同体の構造を形成してきた。

### [塩田区水圧調整師](entities/e20.md)

塩田区水圧調整師は、塩盆地の乾燥環境下で地下導水路の水圧制御と塩面洗掘を担う技術的労働集団である。水番家系が管理権を世襲し、採掘組合が対立する構造の中、塩秤所の計測に基づく塩担と水尺の基準を運用する。塩暦の塩年単位で記録される技術的実践を通じて、水資源配分制約の物理的限界を現実の作業に落とし込む役割を担う。

### [塩面洗掘水圧上限](entities/e21.md)

塩面洗掘水圧上限は、降雨が極めて少ない乾燥環境（s2）と地下導水路への依存（s3）という物理的制約から導き出される技術的限界である。水圧管理庫（e15）が基準水位差1水尺と許容変動幅0.5水尺を維持することで、塩担による産出量と水配分の上限が規定される。この上限は、水番家系と採掘組合の管理権対立を塩秤所の計測基準を通じて制度的に拘束し、塩暦の塩年単位で資源経済の安定性を担保する規範的枠組みとして機能する。

### [乾塩盆地](entities/e24.md)

乾塩盆地は、降雨が極めて少ない内陸の乾燥地域であり、地下の古い導水路からのみ水資源を依存する地理的・気候的条件を有する。この環境下では、塩面洗掘における基準水位差1水尺と許容変動幅0.5水尺の維持が技術上の必須条件となり、水圧管理庫による制御が塩担で測られる産出量と水配分の上限を規定する。生態系は乾燥に適応した限定的な種から構成され、水資源の物理的制約が経済活動と社会構造の基盤を形成している。

### [塩担組合](entities/e27.md)

塩担組合は、塩起の水源確保以降、地下導水路から引く水を用いた塩の採掘に従事する労働集団である。水番家系が管理権を世襲し、導水路統制所が基準水位差1水尺と許容変動幅0.5水尺を管理する構造において、組合は塩担で測られる産出量の確保と労働条件の安定を目的に活動する。塩秤所が計測・記録を行う中立な基準に対し、組合は現場の作業実態と水配分の実効性を重視し、水圧管理庫の制御が及ぼす生産上限に対する対話や調整を通じて、共同体内の権限と義務の境界を巡る交渉を行う。

### [塩田区導水路運用組合](entities/e28.md)

塩田区導水路運用組合は、塩盆地(e1)の乾燥環境と地下導水路依存という制約下で、塩面洗掘の技術的運用を担う労働集団である。水番家系(e12)が管理権を世襲し、採掘組合が対立する構造の中、塩秤所(e13)の計測に基づく塩担と水尺の基準を運用する。塩暦(e16)の塩年単位で記録される技術的実践を通じて、水資源配分制約(e14)の物理的限界を現実の作業に落とし込む役割を担う。
